# Purpose

Commercial Off‑The‑Shelf (COTS) models.

Note: Models in this folder are not to be modified.

# Origins

The file MICROFC-60035-SMT-TR1.stp was downloaded from:
https://fr.farnell.com/en-FR/on-semiconductor/microfc-60035-smt-tr1/sipm-ic-35um-cwdfn-4/dp/2949095

Although it is possible to download the STL format, it fails to open in OpenSCAD. 
The STP file was manually converted to an STL file using FreeCAD.
