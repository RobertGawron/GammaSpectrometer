# Tools

VUnit - testbench automation
GHDL - VHDL simulation/analysis
GTKWave - waveform viewing
SymbiYosys - formal verification
Yosys - synthesis
nextpnr-ice40 - place and route
icepack - bitstream generation
iceprog - FPGA programming
FuseSoC - core/package management
VSG - VHDL style checking
Doxygen - documentation generation
Just - task automation

## Repository Structure

- `Source/` - synthesizable VHDL source files
- `Testbench/` - simulation-only verification sources
- `Simulation/` - simulation configuration and support files
- `Constraints/` - FPGA constraint files
- `Build/` - generated build artifacts (not tracked in version control)
